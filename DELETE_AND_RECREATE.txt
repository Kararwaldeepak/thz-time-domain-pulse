DELETE AND RECREATE THE GITHUB REPOSITORY
=========================================

Repository owner:
Kararwaldeepak

Repository name:
thz-time-domain-pulse

Live site after deployment:
https://kararwaldeepak.github.io/thz-time-domain-pulse/

A. DELETE THE CURRENT REPOSITORY
-------------------------------
1. Open the current thz-time-domain-pulse repository.
2. Select Settings.
3. On the General page, scroll to Danger Zone.
4. Select Delete this repository.
5. Read the warning and continue.
6. Type the full repository name when GitHub requests confirmation.
7. Confirm deletion.

B. CREATE A NEW EMPTY REPOSITORY
--------------------------------
1. Select the + menu at the top right of GitHub.
2. Select New repository.
3. Owner: Kararwaldeepak
4. Repository name: thz-time-domain-pulse
5. Visibility: Public
6. Do not add a README, .gitignore, or license during creation.
7. Select Create repository.

C. UPLOAD THE CLEAN FILES
-------------------------
1. Extract thz-time-domain-pulse-clean.zip on your computer.
2. Open the extracted folder.
3. In the empty GitHub repository, select uploading an existing file.
4. Drag the files INSIDE the extracted folder onto GitHub.
5. Do not upload the ZIP itself.
6. Commit message:
   Initial clean THz time-domain simulation
7. Commit directly to the main branch.

The repository root must contain:

index.html
README.md
theory.md
time_and_frequency_domain_guide.txt
CITATION.cff
LICENSE
.nojekyll

D. ENABLE GITHUB PAGES
----------------------
1. Open Settings -> Pages.
2. Source: Deploy from a branch
3. Branch: main
4. Folder: / (root)
5. Save.
6. Wait for the deployment to finish.
7. Open:
   https://kararwaldeepak.github.io/thz-time-domain-pulse/
8. Force refresh with Ctrl+F5 if an old page is cached.
